# gitunzip-test-fixtures

Sample zip files for testing the [gitunzip](https://github.com/) Chrome extension.

- `sample-project.zip` — nested folders (`src/components`, `assets/images`, `assets/icons`, `docs`, `data`) with text, JSON, CSS, PNG, JPEG, GIF, SVG, and a raw binary file. Good for testing folder navigation and all file preview types.
- `quick-test.zip` — a small flat zip with two files, for quick sanity checks.
